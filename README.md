# 毛筆書寫獨立試作

在本資料夾執行 `python -m http.server 8766 --bind 127.0.0.1`，開啟 http://127.0.0.1:8766/ 。不能直接用 file:// 載入題庫。

## 已包含
- 從所選腔調的五個級別抽取實際去標點後恰為五字的句子，沿用音檔與華語解釋。
- 一字一格；依正規化移動速度調整筆寬，忽略筆壓，支援 Pointer Events。
- 首次沾墨開始計時，完成第五字停止計時。墨量依筆畫走過的距離遞減（`app.js` 的 `INK_SPAN`，約夠寫三個字），墨用完（收筆時剩餘量 <= 0）就必須點墨硯補墨，補墨次數不限：墨少時筆跡變灰變細並出現飛白，墨量提示行與硯台會提醒再沾墨；墨量只影響畫面，不影響計分。結果頁有結算動畫：分數跳動計數、紀念章重重蓋下（卡片微震與漣漪），使用者設定「減少動態」時直接顯示結果。撤回及重寫不重設時間。
- 每字透明筆跡保存、五字作品、書寫評價、10 分制試作得分與揮毫時間（不含排行榜預覽）。
- 1080×1350 PNG 作品圖卡、「複製文案」按鈕（固定格式，結尾評價句取自 `app.js` 的 `FEEDBACK_LINES`，可換成隨機文案）、LINE／Threads／Facebook／Instagram 圖示入口（圖示取自 share_card）。社群分享只給圖片，不附文字與網址：手機開系統分享面板，電腦下載圖片並開啟該平台。

## 評分限制
以標準字形點陣與固定 20/512 字格寬度的書寫軌跡遮罩，計算 coverage 與 precision 的調和平均，五字平均乘 10；筆順另算加分（見下）。畫面筆寬不影響評分。底字範本為楷書筆畫輪廓（見「筆畫資料」），不是真正書法範本；正式上線前需以實際學生作品校準門檻、字形難度及跨設備差異。每字至少覆蓋 12% 才能繼續，這只防止空白或隨意一點送出，不代表寫完整。

## 串接邊界
尚未改動原遊戲、原抽題邏輯、前五題配分或正式排行榜。未虛構競賽總分與排名。
正式串接需傳入五字題、前五題分數及作答耗時、正式課程/單元/題目來源與遊玩網址；在最後頁加入競賽總分和總時間，手寫作品仍為分享主視覺。
作品紀念章依筆墨得分分六階段（墨花亂舞／墨點初試／墨字初成／運筆漸穩／落筆生輝／墨韻客家，2 分以下為亂寫章），門檻與章名在 `app.js` 的 `STAMPS`，分數門檻為暫定值；章是完成書寫的呈現，不是已完成社群分享的證明；分享獎勵的獎項與驗證機制待確認。沒有發放積分或呼叫後端。

## 筆畫資料與筆順
- `strokes/strokes.json`：題庫五字題用到的 46 個字，每字有筆畫輪廓（當灰色底字）與每一筆的中心線（算筆順）。由 `tools/build_strokes.py` 產生（會從 hanzi-writer-data 2.0.1 下載，題庫換了字就重跑）。授權為 Arphic Public License，全文見 `strokes/ARPHICPL.txt`。
- 資料裡沒有的三個客語字，用現有偏旁左右拼出：𠊎＝亻＋厓、𫣆＝亻＋恩、吔＝口＋也（結構依維基詞典）。該字不在資料裡時，底字退回字型、不算筆順。
- 筆順算法（`assessOrder`）：把標準每一筆的中心線對到你筆跡上最近的點，以那一點在整個書寫過程中的先後當作這一筆的時間，再看標準順序裡每一對筆畫你是否先寫前一筆。不要求筆數相同，所以連筆（幾筆一筆寫完）仍可比對；不看筆畫方向；距離太遠沒寫到的筆畫不列入。
- 計分：每字筆順全對最多加 `ORDER_BONUS`（0.15），且跟著形狀分數縮小（形狀不到 0.5 按比例縮小），只加分、不扣分。結果頁多一格「筆順」顯示五字平均正確率。
- 教育部標準核對：用教育部《國字標準字體筆順學習網》的筆順（經 g0v/zh-stroke-data 取得，僅供本機比對，**資料檔不放進本專案**，因該網站授權限非商業教學用途）逐字比對題庫 46 字中的 42 字（咧、吂、吔、𫣆 該資料沒有，改用各偏旁的標準筆順核對）。比對方法：把兩邊每一筆的中心線縮放到同一範圍，看每一筆在另一邊最近的是哪一筆。發現並修正（`tools/build_strokes.py` 的 `fix_to_moe`）：哦的最後兩筆順序相反；過的咼上方短橫與豎順序相反；著、蒙的艹原為「一丨丨」，標準是「丨一一丨」；啊、哪的阝、過的辶、鬼的「田中豎＋撇」原本合成一筆，標準是分開寫，已拆開並調整順序。修正後 42 字的筆數與先後都與標準一致（飽、承、齒、瀝在比對工具上有幾筆因為兩邊字形位置略有差異而被誤報，人工逐筆確認順序相同）。
- 限制：連筆時橋接的線在標準筆畫外，會降低精準度。

## 亂寫偵測
每個字先算覆蓋率與精準度的 F1，再做兩件事：
1. 扣掉「碰巧蓋到」的基本分：隨便畫幾條線經過底字，F1 也有兩三成，所以 `CHANCE_F1`（0.25）以下不算分，超過的部分才換算成 0～1。
2. 另算「筆畫總長 ÷ 底字所需長度」（`SCRIBBLE_*`）：正常書寫約 1～1.5 倍（連筆約 2 倍），來回塗抹或打圈會到 5 倍以上，超過 2.5 倍開始扣分。

程式模擬的結果（單字，滿分 1）：照標準中心線依序描約 0.9～0.97、每點隨機偏移 8px 約 0.8；整格來回塗滿、亂線團、三條長曲線穿過字都在 0.05 以下。連筆（幾筆連成一筆）約 0.75～0.9。門檻尚未用真實學生作品校準；真實手描通常比模擬的中心線偏差大，實際分數會落在中間。

## 高分段嚴格化
單字分（形狀＋筆順加分，上限 1）超過 `STRICT_FROM`（0.7）後再套曲線：0.7 + 0.3 × ((分−0.7)÷0.3)^`STRICT_POW`（1.5），0.7 以下不變。0.8→0.76、0.85→0.81、0.9→0.86、0.95→0.93，越接近滿分越難拿。程式模擬（十個字平均）：依標準中心線依序描約 9.1、偏 4px 約 8.7、偏 8px 約 7.2、整字一筆連寫約 7.4、兩筆一組連寫約 8.4。（曾用 2.2 次方，更嚴：完美描法只有 8.8。）紀念章最高階門檻 9 分，之後要依真實作品調整。
