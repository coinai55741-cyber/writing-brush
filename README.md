# 毛筆描寫獨立試作

在本資料夾執行 `python -m http.server 8766 --bind 127.0.0.1`，開啟 http://127.0.0.1:8766/ 。不能直接用 file:// 載入題庫。

## 已包含
- 從所選腔調的五個級別抽取實際去標點後恰為五字的句子，沿用音檔與華語解釋。
- 一字一格；依正規化移動速度調整筆寬，忽略筆壓，支援 Pointer Events。
- 首次沾墨開始計時，第三字後固定補墨一次，完成第五字停止計時。撤回及重寫不重設時間。
- 每字透明筆跡保存、五字作品、描寫評價、10 分制試作得分與描寫時間（不含排行榜預覽）。
- 1080×1350 PNG 作品圖卡、選填 HTTPS 邀請網址、文案複製（固定格式，結尾評價句取自 `app.js` 的 `FEEDBACK_LINES`，可換成隨機文案）、原生圖片分享與 LINE／Threads／Facebook／Instagram 入口（圖示取自 share_card）。

## 評分限制
以標準字形點陣與固定 20/512 字格寬度的描寫軌跡遮罩，計算 coverage 與 precision 的調和平均，五字平均乘 10。畫面筆寬不影響評分。此為原型，不辨筆順，也不能阻止沿筆畫反覆塗滿。底字採本專案字型，非真正書法範本；正式上線前需以實際學生作品校準門檻、字形難度及跨設備差異。每字至少覆蓋 12% 才能繼續，這只防止空白或隨意一點送出，不代表寫完整。

## 串接邊界
尚未改動原遊戲、原抽題邏輯、前五題配分或正式排行榜。未虛構競賽總分與排名。
正式串接需傳入五字題、前五題分數及作答耗時、正式課程/單元/題目來源與遊玩網址；在最後頁加入競賽總分和總時間，手寫作品仍為分享主視覺。
作品紀念章為完成描寫的呈現，不是已完成社群分享的證明；分享獎勵的獎項與驗證機制待確認。沒有發放積分或呼叫後端。
